# Vibe Specs

## Resources Tab — Visual Layout
**Type:** Visual
**Asset:** None
**Assertion:** The Resources tab panel should display four clearly separated sections (General, Clubhouse Processes, Greens Processes, Farm Processes). Each section should have a visible heading and a card containing labeled rows. The green drive banner at the top should be visually distinct from the section cards. "Coming soon" labels should appear muted/italic, not as primary CTAs. The overall layout should feel consistent with the rest of the portal's cream/green color palette.

## CRM Tab Layout
**Type:** Visual
**Asset:** None
**Assertion:** The CRM contacts list should show a clean grid of contact cards. Each card should prominently display the contact's full name, a type badge (member/guest/etc.) in a muted or brand-adjacent color, and secondary info (phone, email) in smaller text. An empty state (when no contacts exist) should show a friendly message, not a blank div. The "Add Contact" button should be clearly visible in the toolbar at the top of the tab. The overall aesthetic should match the dark green / golf club brand of the rest of the portal.
